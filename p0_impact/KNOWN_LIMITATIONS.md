# Known limitations before first Godot run

The P0 branch is intentionally a first executable hypothesis, not a validated build.

Before expanding scope, verify in Godot on Windows:

- GDScript parses on the project Godot version.
- Touch ray-to-grid selection matches the visible tiles.
- Camera transitions remain readable on the target phone aspect ratio.
- Collision feedback is understandable without reading the numeric message.
- Posture recovery timing matches the intended turn structure.
- Downed presentation remains readable after the enemy capsule rotates.

If any of these fail, fix the P0 rather than adding systems.
