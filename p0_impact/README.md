# LITD: Les Veilleurs — P0 Impact

Prototype goal: validate the core feel of **Coup d’épaule → Push → collision → Posture → À terre** on a 6×5 tactical grid.

## Scope

- 6×5 grid
- Sahen
- 1 Rampant
- 1 wall obstacle
- turn flow
- movement
- basic attack
- Coup d’épaule
- Push 2
- wall collision
- Vitality/Posture
- Downed state
- simple tactical camera

No hub, save system, skill trees, factions, relations, boss logic, procedural generation, or production art in P0.
