# LITD Universe — Règle de cohérence narrative absolue

> Statut : règle transversale obligatoire
> Portée : tous les jeux, textes, dialogues, quêtes, cinématiques, systèmes narratifs et extensions de LITD Universe

## Principe

LITD Universe bannit la « magie scénaristique » : aucun événement ne doit exister uniquement parce que l'histoire en a besoin.

Tout élément important doit avoir une cause, un contexte, des limites et des conséquences compatibles avec le lore général.

Formule directrice :

**Rien n'arrive parce que le scénario l'exige. Tout arrive parce que le monde, les personnages et les règles déjà établies le permettent.**

## Sont interdits

- deus ex machina ;
- faux raccords de chronologie, géographie, technologie, personnage ou causalité ;
- personnage qui sait soudainement quelque chose qu'il ne pouvait pas savoir ;
- objet, pouvoir, faction ou règle introduits uniquement pour résoudre un problème immédiat ;
- changement rétroactif qui contredit un fait canonique sans explication solide ;
- pouvoir surnaturel sans limites définies servant à corriger une impasse narrative ;
- disparition arbitraire d'une conséquence déjà établie ;
- survie, mort, voyage, rencontre ou découverte improbables sans cause suffisante ;
- hasard utilisé pour résoudre un conflit majeur ;
- explication alambiquée créée uniquement pour sauver une contradiction ;
- retcon silencieux ;
- personnage agissant contre sa personnalité sans évolution, contrainte ou information nouvelle suffisante.

## Tout élément majeur doit répondre à ces questions

1. Quelle est sa cause ?
2. Qui pouvait raisonnablement le provoquer ?
3. Quelles règles du monde le rendent possible ?
4. Pourquoi cela se produit-il à cet endroit et à ce moment ?
5. Quelles informations les personnages possèdent-ils réellement ?
6. Quelles conséquences immédiates cela crée-t-il ?
7. Quelles conséquences à long terme devrait-il logiquement laisser ?
8. Est-il compatible avec les autres jeux et périodes ?
9. Si le surnaturel intervient, quelles sont ses limites déjà établies ?
10. Si une coïncidence intervient, déclenche-t-elle seulement une situation ou résout-elle artificiellement le problème ?

## Mystère ≠ incohérence

Un élément peut être inexpliqué pour le joueur sans être inexpliqué pour le canon.

Le mystère peut cacher :
- une cause ;
- une identité ;
- une chronologie ;
- une intention ;
- un mécanisme.

Mais l'équipe d'écriture doit savoir quelle structure logique se trouve derrière, ou marquer explicitement l'élément comme question canonique encore non résolue à traiter avant qu'il ne devienne critique.

## Hasard

Le hasard peut :
- déclencher une rencontre ;
- modifier une route ;
- aggraver une situation ;
- créer une complication.

Le hasard ne doit pas :
- résoudre l'intrigue principale ;
- sauver miraculeusement un personnage sans préparation ;
- fournir exactement l'objet nécessaire au bon moment sans justification ;
- annuler une conséquence majeure.

## Surnaturel

Le surnaturel n'autorise pas l'arbitraire.

Chaque phénomène doit posséder :
- des conditions ;
- des capacités ;
- des limites ;
- un coût ou un risque lorsque pertinent ;
- une cohérence historique ;
- des conséquences observables.

La Rémanence, la Lumière, le Voile, la Folie surnaturelle et toute future force doivent respecter leurs règles de période et ne peuvent devenir des outils universels de correction narrative.

## Personnages

Une décision doit découler au minimum de :
- personnalité ;
- expérience ;
- valeurs ;
- relations ;
- informations disponibles ;
- pression du moment ;
- évolution déjà montrée.

Un personnage peut se contredire, mais cette contradiction doit avoir un sens humain.

## Interconnexion des jeux

Tout nouvel événement majeur doit être évalué dans les deux directions :

- ce qui, dans le passé, le rend possible ;
- ce qui, dans le futur, devrait en rester.

Une absence de trace peut être cohérente si elle possède une raison : destruction d'archives, oubli, tabou, falsification, localisation limitée, secret réel, transformation culturelle, perte linguistique.

## Registre d'incohérences

Toute incohérence détectée doit être classée :

- **BLOQUANTE** : contradiction directe avec un fait canonique majeur ;
- **MAJEURE** : causalité, chronologie, personnage ou règle du monde difficilement compatible ;
- **MINEURE** : détail, vocabulaire, date, géographie ou conséquence locale incohérente ;
- **QUESTION OUVERTE** : information non encore définie qui pourrait devenir contradictoire plus tard.

Pour chaque entrée :
- problème ;
- éléments en conflit ;
- impact ;
- options de résolution ;
- résolution retenue ;
- fichiers à corriger.

Aucune incohérence bloquante ou majeure ne doit être masquée par une explication improvisée.

## Procédure obligatoire pour tout ajout majeur

1. vérifier chronologie ;
2. vérifier géographie et temps de déplacement ;
3. vérifier connaissances des personnages ;
4. vérifier motivations ;
5. vérifier technologie ;
6. vérifier règles surnaturelles ;
7. vérifier conséquences déjà établies ;
8. vérifier continuité inter-jeux ;
9. rechercher une contradiction avec les documents canoniques ;
10. si contradiction : la signaler avant validation et proposer une résolution propre.

## Règle de signalement

Si une incohérence, même ancienne, est découverte pendant une future conception :

**elle doit être signalée explicitement à l'utilisateur au lieu d'être corrigée silencieusement ou contournée.**

Le problème doit être présenté simplement, avec les éléments qui se contredisent et les options de résolution les plus propres.

## Priorité en cas de conflit

1. décisions explicitement verrouillées les plus récentes ;
2. bible générale de LITD Universe ;
3. chronologie canonique ;
4. documents spécifiques au jeu ;
5. quêtes et dialogues ;
6. anciens brouillons ou concepts non verrouillés.

Une décision récente ne doit toutefois pas être utilisée comme prétexte pour créer un retcon incohérent : ses conséquences doivent être propagées proprement dans tout le canon.

## Critère final

Avant de considérer une explication comme satisfaisante, poser la question :

**« Si le joueur connaissait toutes les informations disponibles dans le canon, cette explication lui semblerait-elle naturelle plutôt que fabriquée après coup ? »**

Si la réponse est non, la solution doit être retravaillée.
