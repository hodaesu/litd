# Limite du travail sans PC

Le dépôt contient maintenant la logique et les contrats nécessaires pour démarrer immédiatement la première session 3D. Toute étape supplémentaire qui modifierait proportions, lumière, shader, détails de modèle ou performance sans observation locale serait spéculative. Le prochain jalon utile après fusion est donc la validation visuelle dans Godot/Blender sur PC.
