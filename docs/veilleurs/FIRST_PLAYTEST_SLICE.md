# LITD : Les Veilleurs — tranche de premier playtest

## But

Cette tranche n'est pas le Chapitre I complet. Elle est la version minimale représentative utilisée pour répondre à la question :

> Un nouveau joueur comprend-il les décisions essentielles de LITD et a-t-il envie de repartir en expédition ?

Durée cible : **30 à 45 minutes** pour un testeur naïf.

## Contenu volontairement limité

### 1. Sanctuaire — 3 à 5 min

Le joueur doit seulement :

- comprendre son objectif immédiat ;
- voir ses quatre Veilleurs ;
- vérifier rapidement équipement/formation ;
- partir en expédition.

Aucun tour complet de tous les bâtiments n'est requis.

### 2. Exploration courte — 5 à 8 min

La route doit proposer :

- un embranchement lisible ;
- une interaction facultative ;
- une ressource ou information créant un petit choix ;
- une première conséquence observable.

Le test ne doit pas exiger de lire un grand volume d'archives.

### 3. Combat A — lecture de base — 5 à 7 min

Objectifs d'observation :

- ordre des tours ;
- choix d'une compétence ;
- choix d'une cible ;
- lecture des rangs ;
- anticipation d'une conséquence simple.

Utiliser peu d'ennemis et des comportements facilement lisibles.

### 4. Combat B — position et anatomie — 6 à 8 min

Le combat doit forcer au moins une vraie décision parmi :

- attaquer maintenant ;
- consommer l'action pour repositionner ;
- viser une partie anatomique pour neutraliser une fonction ;
- choisir dégâts immédiats ou contrôle futur.

Le joueur doit pouvoir expliquer après coup pourquoi son choix a aidé ou coûté quelque chose.

### 5. Événement / Peur-Folie — 3 à 5 min

Créer une situation où :

- la cause d'une hausse ou baisse psychologique est visible ;
- l'effet est perceptible ;
- au moins un contre-jeu existe.

Le but n'est pas de montrer toutes les variantes de Peur/Folie.

### 6. Élite ou mini-boss — 5 à 7 min

Réutiliser les mécaniques déjà apprises en les combinant :

- position ;
- anatomie ;
- pression psychologique ;
- ressource limitée.

Pas de nouvelle couche majeure introduite ici.

### 7. Décision finale courte — 2 à 4 min

Proposer un choix avec conséquence claire, par exemple :

- achever / neutraliser / capturer ;
- prendre une ressource / préserver quelqu'un ;
- poursuivre / se retirer.

La conséquence doit être rappelée ou visible au retour.

### 8. Retour Sanctuaire — 3 à 5 min

Le testeur doit pouvoir répondre sans aide :

- qu'est-ce qui a changé à cause de mon expédition ?
- qu'est-ce que je voudrais faire ensuite ?

## Systèmes visibles dans cette tranche

Obligatoires :

- quatre Veilleurs ;
- ordre des tours ;
- compétences de base ;
- positionnement ;
- anatomie/blessure fonctionnelle ;
- Peur/Folie ;
- une décision de capture/neutralisation ou équivalent ;
- conséquence persistante ;
- sauvegarde/reprise.

À masquer ou retarder si non nécessaire au scénario :

- grand nombre de compétences ;
- arbre complet niveau 1–50 ;
- ultimes tardifs ;
- plusieurs systèmes économiques secondaires ;
- totalité des archives ;
- contrats longs ;
- NG+ ;
- contenu des chapitres II–X ;
- systèmes qui n'ont pas de décision utile dans cette session.

## Critères de réussite de la tranche

Le testeur doit être capable, avec ses propres mots, d'expliquer :

1. comment il choisit qui/quoi attaquer ;
2. pourquoi il changerait de position malgré le coût d'action ;
3. pourquoi viser une partie du corps peut être préférable à maximiser les dégâts ;
4. ce qui provoque Peur/Folie et comment il peut réagir ;
5. ce qu'il a sacrifié ou accepté dans sa décision finale ;
6. ce qui a changé au Sanctuaire ou dans le monde ;
7. ce qu'il aimerait faire lors d'une prochaine expédition.

## Signaux d'échec

La tranche doit être retravaillée avant expansion si :

- le joueur demande fréquemment quoi faire ;
- il ne sait pas pourquoi une action est possible ou impossible ;
- le repositionnement semble inutile ;
- l'anatomie est perçue comme seulement gore ;
- Peur/Folie paraît aléatoire ;
- le retour au Sanctuaire ne montre aucune conséquence comprise ;
- le joueur termine sans curiosité pour une deuxième expédition.

## Règle de production

Aucun contenu supplémentaire n'est ajouté pour corriger un problème de compréhension. On corrige d'abord la présentation, les règles, le feedback, le rythme ou le nombre de systèmes exposés.
