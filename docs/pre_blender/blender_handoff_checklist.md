# Checklist — prêt pour Blender

Le passage à Blender est autorisé pour un asset lorsque :

- [ ] son identifiant est fixé ;
- [ ] sa fonction gameplay est connue ;
- [ ] sa référence visuelle est validée ;
- [ ] son échelle et son pivot sont définis ;
- [ ] son rig est choisi si nécessaire ;
- [ ] ses animations nécessaires sont listées ;
- [ ] ses matériaux/textures attendus sont définis ;
- [ ] ses collisions sont prévues ;
- [ ] son chemin cible Godot est fixé ;
- [ ] son niveau de priorité est indiqué ;
- [ ] ses dépendances sont connues.

## Ce qui nécessite réellement Blender

Modélisation polygonale finale, UV définitifs, skinning/weight painting, rigging final, animation 3D finale, baking lié aux meshes et contrôle visuel des déformations.

Tout le reste — architecture logicielle, gameplay, données, nomenclature, contrats d'assets, scènes placeholder, tests, documentation, CI et préparation d'intégration — doit être avancé autant que possible avant cette étape.
