# Index encyclopédique v2 — Créatures

## Vivant réel
Taxonomie, anatomie, taille, masse, habitat, niche, alimentation, locomotion, perception, reproduction, défense, prédation, communication, socialité, cycle de vie, saisonnalité, symbiose, maladie/parasites, traces.

Priorité d’équilibrage : vertébrés ET invertébrés ; terrestre ET marin ; macrofaune ET micro-organismes ; espèces communes ET extrêmophiles.

## Éteint
Période géologique, reconstruction scientifique, incertitude, locomotion, écologie, analogues modernes. Les représentations artistiques modernes restent protégées ; la bibliothèque utilise les connaissances paléontologiques, pas un paleoart à copier.

## Mythique/mythologique
Nom traditionnel, culture/peuple, aire, sources anciennes/ethnographiques, variantes, fonction, apparence décrite, comportement, symbolique, caractère sacré/vivant culturellement, sensibilité, transformations modernes à ignorer.

## Génération LITD
Créer via matrice : 2–4 traits biologiques + 1 contrainte de milieu + 1 besoin/comportement + 1 thème narratif. Changer silhouette, proportions, comportement et contexte jusqu’à obtenir une identité autonome.
