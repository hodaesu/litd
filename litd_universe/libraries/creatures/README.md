# Bibliothèque — Créatures

## Axes
Anatomie comparée, locomotion, alimentation, défense, prédation, reproduction, cycle de vie, habitat, comportement social, camouflage, communication, silhouette, masse, vulnérabilités et lisibilité du danger.

## Sources d’inspiration
Mammifères, oiseaux, reptiles, amphibiens, poissons, arthropodes, mollusques, annélides, cnidaires, organismes microscopiques et fossiles ; folklore étudié pour ses thèmes et fonctions narratives, jamais pour copier une incarnation protégée.

## Méthode
Combiner plusieurs mécanismes biologiques et besoins écologiques pour créer une espèce LITD originale. Interdiction de reproduire les monstres reconnaissables d’autres franchises.
