# Bibliothèque — Effets visuels

## Axes
Timing, anticipation, pic d’impact, dissipation, silhouette, densité, particules, fluides, lumière, chaleur, fumée, poussière, débris, sang, étincelles, magie, lisibilité du gameplay et interaction avec les matériaux.

## Références
Phénomènes physiques réels, photographie scientifique, cinéma, animation et jeux peuvent être analysés, mais les effets signature de propriétés intellectuelles restent `REFERENCE_ONLY`.

## Création LITD
Définir pour chaque effet une logique de matière, une fonction de gameplay, un rythme et une grammaire visuelle propres à LITD. Les VFX intégrés doivent être originaux ou licenciés.
