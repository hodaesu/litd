# Catalogue v1 — Animation et mouvement

Statut : `L3_PRODUCTION_FULL_V1`.

Humain : marche, course, sprint, fatigue, boiterie, montée, descente, escalade, saut, réception, chute, roulade, ramper, pousser, tirer, porter, lancer, travailler, danser, s’agenouiller, se relever.

Combat : transfert de poids, garde, esquive, frappe, recul, parade, impacts, perte d’équilibre ; étudier principes biomécaniques de disciplines mondiales sans copier une chorégraphie protégée.

Animaux : quadrupèdes, oiseaux, reptiles, amphibiens, poissons, insectes, arachnides, céphalopodes, serpents, animaux fouisseurs et nageurs.

Créatures : combiner anatomie + masse + surface + intention. Chaque mouvement doit révéler poids, centre de gravité, respiration, niveau d’énergie et état émotionnel.

Animation externe : `REFERENCE_ONLY`; mocap/animation de production exige droits explicites.
