# Bibliothèque — Lore commun

Cette bibliothèque contient uniquement les faits de canon susceptibles d’être partagés par plusieurs jeux de LITD Universe. Elle ne doit pas absorber les systèmes de gameplay propres à un titre.

## Champs recommandés
`id`, `title`, `canon_status`, `era`, `location`, `people`, `factions`, `sources`, `dependencies`, `contradictions`, `relevant_games`, `last_reviewed`.

## Statuts
- `PROPOSAL` — idée non validée ;
- `CANON` — fait officiel Universe ;
- `GAME_SPECIFIC` — renvoi vers le dossier du jeu concerné ;
- `DEPRECATED` — ancien canon conservé pour traçabilité.

## Règle de séparation
Le lore partagé peut être consommé par tous les jeux, mais les mécaniques, équilibrages, arbres de compétences, contrôles, architecture technique et autres systèmes spécifiques restent dans leurs projets respectifs.
