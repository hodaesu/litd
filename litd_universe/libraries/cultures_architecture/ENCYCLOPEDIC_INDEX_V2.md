# Index encyclopédique v2 — Cultures & architecture

## Habitat
Nomade, semi-nomade, village, maison longue, maison à cour, maison-tour, habitat troglodyte, habitat sur pilotis, ferme, palais, monastère, fort, caravansérail, auberge, logement collectif, quartier marchand.

## Architecture publique
Marché, tribunal, assemblée, école, bibliothèque, bain, hôpital historique, grenier, entrepôt, port, atelier, forge, moulin, mine, carrière, pont, barrage, aqueduc, canal, citerne, puits, fontaine.

## Architecture religieuse/funéraire
Temple, sanctuaire, église, monastère, mosquée, madrasa, stupa, pagode, tombe, nécropole, tumulus, mausolée ; tous contextualisés, jamais transplantés tels quels.

## Défense
Mur, fossé, palissade, bastion historique, porte, tour, citadelle, château, fort de montagne, refuge.

## Lecture LITD
Climat → ressources → technique → société → circulation → lumière → défense → vieillissement. Les monuments reconnaissables servent à étudier des solutions, pas à fournir des décors à copier.
