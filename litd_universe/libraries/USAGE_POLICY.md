# Politique de droits et d’utilisation — LITD Universe

## 1. REFERENCE_ONLY — statut par défaut

Utilisé pour toute œuvre, propriété intellectuelle, culture visuelle, design, enregistrement, chorégraphie, texte, musique ou autre source extérieure dont l’usage comme asset n’est pas explicitement autorisé.

Autorisé : analyser des principes généraux, documenter le contexte, comparer plusieurs influences, noter ce qui fonctionne et créer ensuite une proposition LITD originale.

Interdit : copier une composition reconnaissable, un personnage, une créature, un costume, une arme fictive, un accessoire distinctif, une sculpture, une pose iconique, un motif signature, un texte protégé, une mélodie, une chorégraphie, un effet visuel signature, une texture ou un modèle tiers.

## 2. LITD_ORIGINAL_REUSABLE

Asset original créé pour LITD et détenu par LITD Universe. Il peut être partagé entre LITD 1, LITD 2 et de futurs jeux si son entrée l’autorise. Cela peut inclure bruitages, ambiances, textures originales, modèles, animations, VFX, musiques, UI ou autres assets internes.

## 3. LICENSED_REUSABLE

Asset tiers dont la licence autorise explicitement l’usage prévu. Chaque entrée doit documenter la source, la licence, l’auteur, l’attribution éventuelle, le périmètre commercial, les plateformes et les restrictions.

## Audio et bruitages

Un bruitage n’est pas automatiquement libre de réutilisation. Un fichier audio peut être partagé entre jeux uniquement s’il est `LITD_ORIGINAL_REUSABLE` ou `LICENSED_REUSABLE`. Un son extérieur utilisé pour étudier un timbre, une ambiance ou un impact reste `REFERENCE_ONLY`.

## Sécurité de propriété intellectuelle

- droits inconnus = `REFERENCE_ONLY` ;
- ne pas importer dans les assets de production une référence protégée ;
- conserver les références comme métadonnées, liens et notes d’analyse lorsque possible ;
- vérifier les licences avant toute intégration ;
- éviter la dépendance à une seule œuvre identifiable ;
- privilégier une synthèse de plusieurs références et des sources factuelles/historiques ;
- signaler les marques, personnages, franchises et designs reconnaissables ;
- traiter les symboles sacrés et patrimoines culturels sensibles avec prudence.

## Test avant intégration

Avant qu’un asset entre dans un jeu :
1. identifier son origine ;
2. vérifier `usage_class` ;
3. documenter les droits ;
4. confirmer qu’il ne reproduit pas une référence identifiable ;
5. confirmer que la création possède une identité LITD propre.
