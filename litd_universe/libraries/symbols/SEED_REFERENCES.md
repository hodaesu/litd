# Références initiales — Symboles

Le but est d’étudier les mécanismes symboliques, pas de reprendre les emblèmes.

- Cercle / disque — totalité, cycle, astre : significations variables selon cultures.
- Spirale — croissance, mouvement, temps ; occurrences indépendantes multiples.
- Axe vertical / arbre cosmique — connexion des niveaux du monde ; nombreuses traditions distinctes.
- Labyrinthe / méandre — parcours, seuil, répétition.
- Nœud / entrelacs — continuité, lien, protection selon contextes.
- Soleil/lune — calendriers, dualités, souveraineté, cycles ; éviter de reprendre emblèmes religieux précis.
- Main/œil — protection, perception, pouvoir ; motifs souvent sacrés.
- Masque — transformation, ancêtre, théâtre, rite ; forte sensibilité culturelle.
- Serpent — régénération, danger, eau, souveraineté selon contexte.
- Montagne — centre, frontière, sacré, refuge.
- Couleurs cardinales et cosmologies directionnelles — documenter chaque tradition séparément.
- Systèmes adinkra, mandalas, glyphes religieux, motifs autochtones : étude contextuelle uniquement, pas de copie décorative.

Tout symbole LITD doit avoir une construction interne au lore et une géométrie originale.
