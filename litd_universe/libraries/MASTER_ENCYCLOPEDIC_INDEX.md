# Index encyclopédique maître — LITD Universe

Niveau : `L4_CONTINUOUS_ENCYCLOPEDIC`.

Cet index transforme les bibliothèques en base de conception interrogeable. Toute nouvelle entrée doit porter au minimum : domaine, sous-domaine, aire géographique, période, matière/médium, fonction, source, statut de droits, axes d’inspiration, éléments interdits à copier, liens vers domaines voisins.

## Axes transversaux obligatoires
- géographie : Afrique, Europe, Asie, Océanie, Amériques, Arctique/Antarctique, mers et océans ;
- temps : préhistoire, Antiquité, périodes médiévales, époque moderne, contemporaine lorsque pertinente, paléontologie/géologie pour le vivant ;
- milieu : urbain, rural, désertique, forestier, montagnard, côtier, fluvial, souterrain, marin, abyssal ;
- échelle : micro, humain, architectural, territorial ;
- fonction : nourrir, protéger, déplacer, communiquer, croire, gouverner, combattre, travailler, créer, soigner, habiter ;
- matérialité : minéral, métal, bois, fibre, peau/cuir, céramique, verre, organique, fluide, lumière, son ;
- état : neuf, usé, réparé, rituel, abandonné, brûlé, noyé, gelé, corrodé, contaminé, fossilisé ;
- droits : `REFERENCE_ONLY`, `LITD_ORIGINAL_REUSABLE`, `LICENSED_REUSABLE`.

## Règle de synthèse
Une production LITD doit pouvoir citer plusieurs principes d’inspiration mais ne doit pas devenir reconnaissable comme reproduction d’une œuvre ou d’une propriété intellectuelle tierce.
