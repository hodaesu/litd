# Index encyclopédique v2 — Technologies

## Chaînes de production
Extraire → transporter → transformer → assembler → entretenir → réparer → recycler. Toute technologie est reliée aux ressources et aux métiers nécessaires.

## Domaines
Agriculture, élevage, pêche, conservation, eau/irrigation, construction, pierre, terre, bois, textile, cuir, céramique, verre, métallurgie, énergie hydraulique/éolienne, mécanique, transport terrestre, navigation, cartographie, écriture, comptabilité, mesure, astronomie, imprimerie historique, médecine/hygiène historiques, stockage, logistique, fortification.

## Comparaison mondiale
Pour chaque fonction, documenter plusieurs solutions régionales au lieu de choisir une civilisation comme norme unique.

## Canon LITD
Filtrer par époque et niveau technologique du jeu concerné. Une référence moderne peut expliquer un principe physique, mais ne devient pas automatiquement une technologie disponible dans l’univers.
