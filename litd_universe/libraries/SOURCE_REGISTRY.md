# Registre des sources — LITD Universe

Vérifié le 2026-08-31. Toute entrée tierce reste `REFERENCE_ONLY` par défaut, même si le média source est dans le domaine public ou sous CC0. Le statut de réutilisation directe doit faire l’objet d’une décision séparée.

| ID | Source | Usage LITD | Droits / vigilance |
|---|---|---|---|
| MET_OA | The Metropolitan Museum of Art — Open Access | arts, objets, textiles, armes, sculptures, peintures | images d’œuvres du domaine public + données OA sous CC0 ; inspiration par défaut |
| SMITHSONIAN_OA | Smithsonian Open Access | arts, sciences, histoire, technologie, zoologie, 2D/3D | vérifier le marquage CC0 de chaque item ; inspiration par défaut |
| EUROPEANA | Europeana | patrimoine culturel européen et collections partenaires | droits variables par objet ; lire le rights statement |
| BRITISH_MUSEUM | British Museum Collection Online | cultures matérielles, objets, sculptures, antiquités | images souvent soumises à conditions ; référence uniquement sauf licence explicite |
| GBIF | Global Biodiversity Information Facility | taxonomie, occurrences, biodiversité mondiale | données ouvertes ; licence des médias variable par occurrence |
| BHL | Biodiversity Heritage Library | littérature zoologique/botanique, planches historiques, taxonomie | accès ouvert ; vérifier les droits de chaque volume/image |
| IUCN | IUCN Red List | écologie, menaces, répartition, biologie de conservation | données de référence ; ne pas réutiliser médias sans autorisation |
| UNESCO_ICH | UNESCO Intangible Cultural Heritage | gestes, artisanats, rituels, musiques, traditions | documentation culturelle, jamais licence de reproduction d’un motif ou rituel |

## Règle d’or
Une licence ouverte autorise éventuellement une réutilisation juridique ; elle n’annule jamais la règle créative LITD : ne pas reproduire servilement une œuvre, une silhouette, un motif, une composition, un personnage ou une interprétation reconnaissable. Croiser plusieurs sources et transformer les principes observés.
